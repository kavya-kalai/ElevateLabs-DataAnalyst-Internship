Task 6: Data Visualization - Python Charts for Insights

Internship: Data Analyst Internship (MSME) 

📌 Project Overview
The objective of this task was to transform cleaned data into actionable visual insights using Python. I utilized Matplotlib and Seaborn to create various chart types that reveal hidden patterns, such as seasonal trends, sales distributions, and variable correlations.



📊 Visualizations Created

Bar Chart: Identified the top 10 products/categories by total revenue to highlight primary business drivers.


Line Chart: Analyzed time-series data to visualize sales trends over months and identify seasonal peaks.


Histogram: Examined the distribution of numeric variables like profit and ratings to detect skewness and outliers.


Scatter Plot: Explored the correlation between key variables (e.g., GDP vs. Happiness or Revenue vs. Profit).


📂 Deliverables

Task6_Visualization.ipynb: The full technical notebook with code and interpretations.


charts_output.pdf: A high-quality export of all generated visualizations.


README.md: Documentation of project goals and findings.

💡 Key Business Insights

Trend Analysis: The line chart indicates a significant sales increase during the final quarter, suggesting a heavy reliance on holiday-driven consumer behavior.


Product Performance: A small group of top-performing categories accounts for the majority of total sales, indicating a need for targeted inventory management.



Variable Correlation: The scatter plot shows a positive correlation between GDP and happiness scores, supporting the theory that economic stability influences national well-being.
