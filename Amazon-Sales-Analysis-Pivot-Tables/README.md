# Task 2: Amazon Sales Analysis - Pivot Tables & Summary Insights

## 📌 Project Overview
The objective of this task was to perform data summarization and aggregation on an **Amazon Sales Dataset**. I utilized **Pivot Tables**, **Slicers**, and **Charts** to transform raw transaction data into an interactive reporting dashboard.

## 🛠️ Key Steps Taken
* [cite_start]**Data Preparation:** Cleaned the dataset and converted it into a **Table Format** to ensure dynamic data updates[cite: 14, 15].
* [cite_start]**Pivot Table Summarization:** Created summaries for **Total Sales by Category** and **Popularity by Rating Count**[cite: 16].
* [cite_start]**Advanced Metrics:** Added a calculated column for **Profit Margin** to analyze segment efficiency[cite: 19].
* [cite_start]**Interactive Dashboard:** Implemented **Slicers** (Category/Rating) and **Pivot Charts** for visual storytelling and easy data exploration[cite: 18, 20].
* [cite_start]**Data Validation:** Applied **Conditional Formatting** to highlight top-performing segments and verified all numeric data types[cite: 17].

## 📂 Deliverables
* **`Pivot_Report.xlsx`**: Full analysis workbook including raw data and pivot tabs.
* **`Pivot_Report.pdf`**: Professional export of the analysis dashboard for stakeholder review.
* **`Insights.docx`**: Detailed summary of 5 key business findings derived from the analysis.

## 💡 Key Business Insight
* **Top Performance:** The Electronics category drives the highest revenue, while high customer engagement (rating count) is directly correlated with discounted price points.
